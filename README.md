# 나의 진로 여정

대학생이 하고 싶은 일을 발견하고, 목표까지의 실행 계획을 구체화하도록 돕는 진로설계 웹 워크북입니다.

## 주요 흐름

1. 이름 입력
2. 하고 싶은 일 자유 서술
3. 작성 내용 기반 피드백 확인
4. 목표 달성 여정 구체화
5. 별점 만족도와 전체 과제 결과를 Supabase에 저장

## Supabase 준비

Supabase SQL Editor에서 `supabase/schema.sql`을 한 번 실행하면 제출 저장이 활성화됩니다.

## 실행

```bash
pnpm install
pnpm dev
```
